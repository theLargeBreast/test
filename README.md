## Kelly Right Real Estate Scraper

This repository now includes a comprehensive web scraper for extracting realtor contact information from Kelly Right Real Estate's website.

### Features
- Extracts agent names, titles, phone numbers, email addresses, biographies, and specialties
- Supports both CSV and JSON output formats
- Includes comprehensive error handling and logging
- Respectful scraping with configurable delays
- Flexible URL discovery and agent page detection

### Files
- `kelly_right_scraper.py` - Main scraper implementation
- `scraper_config.py` - Configuration file
- `test_scraper.py` - Test suite with sample data
- `example_usage.py` - Usage examples
- `README_scraper.md` - Detailed documentation
- `requirements.txt` - Python dependencies

### Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Update the URL in `scraper_config.py` with the correct Kelly Right domain
3. Run the scraper: `python kelly_right_scraper.py`
4. Check the generated CSV and JSON files for results

See `README_scraper.md` for detailed documentation and usage examples.
